# CyberPunk character model

Two textured GLB versions of the same character mesh (about 966k faces, 4096 px textures), generated with ComfyUI (Pixal3D / TRELLIS.2).

- `CyberPunk_textured_00001_.glb` – textured from the front view only; best front side.
- `CyberPunk_textured_MV_00001_.glb` – textured from front, back and side views; best back side.

The files are stored with Git LFS.
